IMAGENS DO SITE

As cinco imagens fotográficas ilustrativas originalmente armazenadas no Manus foram exportadas para esta pasta em formato WebP. Os HTMLs usam caminhos locais `/img/*.webp`; o build copia os arquivos para `dist/img/` e eles são versionados no GitHub para que a publicação na Vercel os sirva. O retrato real do advogado é um arquivo separado. Não use imagens do advogado, equipe, cliente ou casos sem autorização.

Arquivos previstos: hero.webp (horizontal 16:9); sobre.webp (4:3); assessoria-em-leiloes-de-imoveis.webp (4:3); analise-documental-imobiliaria.webp (4:3); contratos-imobiliarios.webp (4:3).
